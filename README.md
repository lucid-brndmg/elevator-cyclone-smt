# Elevator Control System Modelling in Cyclone and SMT

Graph-based modelling of an elevator control system in Cyclone with multiple rounds of evaluations. Materials of this repository appeared on *Verifying an Elevator Scheduling Control System* by Huan Zhang, Haoyang Lu, Long Cheng and Hao Wu. 

## Contents

All SMT formulae are generated by both [Cyclone (Java)](https://cyclone.cs.nuim.ie/) (official release) and [Cyclone (Rust)](https://github.com/lucid-brndmg/cyclone-rs) (experimental compiler).

### Scripts

Code generation scripts are placed at `/scripts`. All scripts are written in JavaScript and requires [Node.js](https://nodejs.org/en) (or Bun) runtime installed. Brief description: 

- `liftblast.js` is for Cyclone model generation where parameters of `n`, `k`, etc... can be passed in as JSON format (see sourcecode) or manually changed in-need. 
- `manifest.js` is a library-purposed file containing basic information of directories of compilers and solvers. 
- `liftcase.js` generates Cyclone spec with SMT formulae of scenario testing.
- `liftprop.js` generates Cyclone spec with SMT formulae of property checking.

To use any above script, one may explicitly update corresponding variables (e.g. output directory) of the script. 

To generate a 3-floor static elevator model that initially idled at L1 with initial up and down request at L1, car request at L0 and path length of 26:
```shell
node ./scripts/liftblast.js '{"optN":3,"optK":26,"optPropCheck":false,"optDebug":false,"optEffect":false,"optOut":"example.cyclone","initFloor":1,"initReqUp":[1],"initReqDown":[1],"initReqCar":[0],"initMode":"I"}'
```

To solve a Cyclone model using Z3 by Cyclone-Java:
```shell
# optionally one needs to use -Xss parameter to expand size of stack
java -jar cyclone.jar in.cyclone
```

To compile a Cyclone model to SMT2 via Cyclone-Rust:
```shell
cyclone-native in.cyclone --codegen out.smt2
```

To compile a Cyclone spec to SMT2 of BV theory via Cyclone-Rust:
```shell
# compiles an SMT2 formulae with integers replaced to 8-bit signed BVs
cyclone-native in.cyclone --codegen out.smt2 --option-bv-int --option-bv-int-size 8
```

For other usages please see related documents. 

### Properties

Property checking specifications are placed at `/prop` of 3, 5, 10, 15 floors respectively, where `stc` denotes fixed configuration, `dyn` denotes dynamic configuration. 

### Scenarios

Scenario testings of 10 scenarios are listed at `/scene`.
